Sunset Ledger — a GTA VI trophy guide & tracker for PlayStation 5. All 55 trophies (1 Platinum, 2 Gold, 6 Silver, 46 Bronze), each with an own-word guide and cited steps from real guides — PowerPyx, Exophase, PSNProfiles, KeenGamer, PushSquare and GameMapa. The tracker saves your progress in the browser, with search and kind/grade filters, a hide-earned switch, a spoiler setting that masks story trophies until earned, and progress export/import. A five-stage roadmap lays out the ~200-hour path to the platinum, the single potentially missable trophy (Positive Mental Attitude, Chapter 1) is called out with the save strategy, and the 5 trophies whose methods are still unconfirmed are flagged honestly instead of invented. Runs fully offline: it makes no network request and uses no Rockstar artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no dependencies — static files only.
